# Raquel Meléndez - Portal Inmobiliario CBF

Sitio web y portafolio profesional de Raquel Meléndez, Asesora Inmobiliaria.

## Tecnologías Utilizadas

- **Vite**
- **React 18**
- **TypeScript**
- **Tailwind CSS**
- **shadcn/ui**

## Desarrollo Local

```bash
# Instalar dependencias
pnpm install

# Iniciar servidor de desarrollo
pnpm dev

# Compilar para producción
pnpm build
```
